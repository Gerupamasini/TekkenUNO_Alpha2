# 鉄研UNOオンライン ルール仕様（v2）

このファイルがゲームルールの正です。`src/shared/engine.ts` はこの内容どおりに実装し、`test/engine.test.ts` で確認しています。

- 元資料：鉄研UNO取扱説明書（98期 木佐木優真）
- 取説にない部分：「鉄研UNO 作り直し：不明点リスト」への回答（2026-09-23）で決定

---

## 1. カード

- 108枚：4色（赤R・緑G・青B・黄Y）× {0×1枚、1〜9×各2枚、SKIP×2、REVERSE×2、DRAW2×2} ＋ WILD×4 ＋ WILD4×4
- 点数：数字＝書かれた数、SKIP・REVERSE・DRAW2＝20点、WILD＝30点、WILD4＝50点
- 「完全に同じカード」＝種類・色・数字がすべて同じ。WILD同士、WILD4同士は全部同じカード扱い

## 2. ルーム

- 合言葉で入室する（ゴッドフィールドの隠れ乱闘方式）。同じ合言葉の人は同じ部屋に入る。部屋がなければ作られる。部屋一覧は公開しない
- 合言葉は前後の空白を除き、全角・半角をそろえ（NFKC）、英字の大文字・小文字を区別しない
- 最初に入った人がホスト。ホストが退室するか20秒以上切断すると、在室中の参加者（入室が早い順）、いなければ観戦者に自動で移る
- 参加者は2〜10人、観戦者は最大20人
- ゲーム中に入った人は観戦者になる。観戦者は「次のゲームから参加」を予約できる
- ホストだけができること：START、END GAME（途中終了）、キック
- NEXT ROUND（結果画面からロビーへ）：結果確定後、参加者なら誰でも
- 全員の接続が切れてから10分たつと部屋は消える（成績も消える）

## 3. 名前・切断・退室・キック

- 名前は最大12文字。部屋の中で同じ名前がいれば末尾に（2）などを付ける
- ブラウザに端末ごとの鍵を保存し、再読み込み・スマホのスリープ・回線切れから同じ席に戻れる
- ゲーム中は退室できない（途中退出なし）。タブを閉じるなどで切れても、席はゲーム終了まで残り、成績も通常どおり記録する
- 切断中の人の手番は10秒だけ待ち、時間切れの処理をする（14章）
- キック（ホストのみ。ロビーはメンバー一覧から、ゲーム中・結果画面はメニューから）
  - ロビー・結果画面：部屋から外す
  - ゲーム中：部屋から外し、席はゲーム終了まで切断中と同じ扱いで残す。成績も通常どおり記録
  - キックは入室禁止ではない。キックされた人も合言葉を入れ直せば同じ部屋に戻れる。ゲーム中に戻った場合は観戦者として入り、元の席はその試合が終わるまで自動で進む（「次のゲームから参加」の予約はできる）

## 4. ゲーム開始

1. ホストがSTARTを押す。接続中の参加者が2人以上必要。切断中の参加者は観戦（次ゲーム参加予約つき）に回す
2. 参加予約した観戦者は、空きがあれば予約順に参加者になる
3. 席順をランダムに並べ替える。画面の並び＝時計回り＝通常の手番順
4. 最初の手番の人をランダムに決める
5. 各自に7枚配る
6. 山札の一番上を初期場札にする。どのカードでもよい（引き直しなし）
7. 初期場札の効果は最初の人が受ける

| 初期場札 | 効果 |
| --- | --- |
| 数字 | なし |
| SKIP | 最初の人を飛ばし、その次の人から |
| REVERSE | 向きを反転。最初の人はそのまま |
| DRAW2 | 最初の人に累積2（返し可） |
| WILD | 色の指定なし。最初の人は何でも出せる |
| WILD4 | 最初の人に累積4（WILD4で返し可）。色の指定なしなので、累積を引いた後の次の人は何でも出せる |

- 初期場札にもカットイン・ドボンできる。初期場札へのドボンには被ドボン者がいない（12章）

## 5. 手番の行動

### 出す

- 1枚目は場札に出せるカードであること
  - WILD・WILD4：いつでも出せる
  - 数字：同じ色か同じ数字
  - 記号（SKIP・REVERSE・DRAW2）：同じ色か同じ種類
  - 数字と記号の組み合わせ：同じ色
  - 場札がWILD・WILD4のときの「色」は指定色。指定色がなければ何色でもよい
- 重ね出し：2枚目以降は、直前のカードと同じ数字（数字カード）か同じ種類（記号カード）。色は問わない。DRAW2とWILD4は混ぜられない
- 出した順に捨て札に積み、最後の1枚が場札になる
- 最後の1枚がWILD・WILD4なら色を1回だけ指定する（必須）
- 場札点（ドボン判定に使う点）＝その1回で出したカードの点数の合計

### ドロー

- 累積ドローがなければ、1手番に1回だけ1枚引ける。出せるカードがあっても引いてよい
- 引いた後は、引いたカードに限らず手札のどのカードでも出せる（重ね出しも可）。出さないならPASS
- 引いても制限時間は延びない

### パス

- ドローした後だけできる

### 累積ドロー

- DRAW2は1枚につき+2、WILD4は1枚につき+4を累積に加える
- 累積を受けた人が出せるのは返し札だけ。場札がDRAW2ならDRAW2かWILD4、場札がWILD4ならWILD4のみ（同じ種類の重ね出しは可）
- 返さないならDRAWで累積分をまとめて引き、手番終了（そのターンは出せない）。累積中はPASSできない

## 6. カード効果

効果の基準は「出した人」の席。カットインなら「カットインした人」の席。

- SKIP：k枚出したら2k席進む（1枚なら1人飛ばし。旧実装どおり。4人戦で2枚なら自分の番に戻る）
- REVERSE：出した枚数が奇数なら向きを反転、偶数なら変化なし。2人戦でも普通に相手の番
- DRAW2・WILD4：累積に加えて次の人へ

## 7. カットイン

- 場札と完全に同じカードを持っていれば、手番に関係なく出せる。自分が出したカードに自分でカットインしてもよい
- 同じカードを複数持っていれば、まとめて出せる（WILD・WILD4など）。違うカードは混ぜられない
- 受付：場にカードが出てから、手番の人がドローするかカードを出すまで
- カットインした人の次の人の番になる（間の人は飛ばされる）。SKIPなら2人目、ドロー札なら累積に加えて次の人へ
- WILD・WILD4でカットインしたら、カットインした人が色を選び直す
- 早い者勝ち（サーバーに先に届いた方）

## 8. 手札が0枚になったら

- カードを出して手札が0枚になったら、すぐ2枚引く（手番は終わる）
- 最後の1枚を出した直後にドボンされた場合も、2枚引いた後の手札で計算する

## 9. UNO

- 手札が1枚になったら自動で「UNO!」の演出を出す。宣言は不要でペナルティもない

## 10. ドボン

- 条件：自分の手札点の合計 ＝ 場札点
- 受付：場にカードが出てから、手番の人がドローするかカードを出すまで（カットインと同じ）
- 被ドボン者：そのカードを出した人（カットインならカットインした人）。初期場札なら被ドボン者なし
- 自分が出したカードにはドボンできない
- ドロー直後の禁止：カードを引いた人は、次に誰かがカードを出すまでドボンできない。通常ドロー、累積ドロー、時間切れの自動ドロー、手札0枚の補充すべてが対象
- 受付中なら誰でも押せる。外しても何も起きない（ペナルティなし、他の人の受付にも影響しない）。画面は「ドボンできるか」を教えない
- ドボンが成立するとゲーム終了、結果フェーズに入る
- 場札がドロー札で累積が残っていれば、累積を受けるはずだった人（手番の人）がまず累積分を引いてから点数を計算する

## 11. 結果フェーズ（10秒）

最初のドボンから10秒間、次の2つを受け付ける。

- 追加ドボン（ダブロン、トリロン…）：条件を満たす人は追加でドボンできる。ドロー直後の禁止は有効なので、累積を引かされた人は加われない
- ドボン返し：被ドボン者は、自分の手札点 ＝ 場札点ならドボン返しできる

ドボン返しが成立した時点で結果は確定し、以降の追加ドボンはできない。返しをさらに返すことはできない。
10秒たつか返しが成立すると結果が確定し、成績に記録する。確定後は参加者なら誰でもNEXT ROUNDでロビーに戻れる。

## 12. 得点（小さいほど良い）

| 場面 | ドボンした人 | 被ドボン者 | その他 |
| --- | --- | --- | --- |
| ドボン（n人） | 0点 | 手札点×2^n | 手札点 |
| 初期場札へのドボン | 0点 | なし | 手札点 |
| ドボン返し | 返した人0点 | 元のドボン者は各自の手札点×2 | 手札点 |

- ドボンに関係なく0点だった人には印を付ける

## 13. 成績（ルームがある間だけ）

- 記録するのは確定したドボン結果だけ。END GAMEによる途中終了は記録しない
- 集計：試合数、累計点、平均、最高、ドボン数と率、被ドボン数と率
- ドボン数・被ドボン数は「ドボンした人→された人」の組ごとに数える。ダブロンなら被ドボン者は+2
- ドボン返しは、返した人はドボン0・被ドボン0（点数は0点）、返された元のドボン者はそれぞれ被ドボン+1（ドボンは0）
- 退室やキックのあと、同じ端末・同じ名前で入り直した人は同じ人として成績を続けて数える。名前を変えて入り直した場合は別の人として数える
- ゲーム中は隠し、ボタンで表示する

## 14. 制限時間

- 手番は30秒。切断中の人は10秒
- 時間切れの処理
  - 累積中：累積分を引いて手番終了
  - 未ドロー：1枚引いてPASS
  - ドロー済み：PASS
- 時間切れの自動ドローも「ドロー」として扱う（ドボン・カットインの受付が終わり、ドロー直後の禁止がかかる）
- 手番中の人が再接続したら、残り時間を最低5秒は確保する

## 15. 山札切れ

1. 場札（直前の1回で出されたカード）以外の捨て札を切り直して山札にする
2. それでも足りなければ、新しい108枚を1セット山札に追加する

## 16. 途中終了

- ホストはゲーム中にEND GAMEできる。ロビーに戻り、成績には記録しない
